# Transactional Email Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Better Auth sends invitation, email-verification and password-reset emails. The emails are designed in Maizzle 6, rendered in en-US or id-ID with escaped dynamic values, and delivered through Cloudflare Email Service (queued with retries when a queue is bound), falling back to the console under `nitro dev`.

**Architecture:** A new platform-free package `@taman/emails` holds Maizzle templates (`emails/*.vue`, layout plus `{{slot}}` placeholders), a codegen step that commits them as TS modules, JSON locale copy with `{param}` tokens, and `renderEmail(job)`. The backend (`apps/api/server/email/`) adds an `EmailSender` (Cloudflare or console) and an `EmailDispatcher` (queue or inline), chosen by which Worker bindings exist, plus a `cloudflare:queue` consumer. Better Auth callbacks build an `EmailJob` and dispatch it.

**Tech Stack:** TypeScript 6, Maizzle 6 (`@maizzle/framework` ^6.1.7, `maizzle` CLI ^1.2.4, build time only), Nitro 3.0.260903-beta (cloudflare preset), Better Auth 1.7.5, Cloudflare Email Service + Queues, vitest 5, consola, pnpm catalogs.

**Spec:** `docs/superpowers/specs/2026-09-29-transactional-email-design.md`

## Review Focus

1. **User-controlled names shown literally.** An org or inviter name containing `<script>`, `{{actionUrl}}`, `{inviterName}` or `$&` must appear as literal (escaped) text and never be interpreted. Pinned by `render.test.ts` / `slots.test.ts` single-pass tests (Task 1) and `templates.test.ts` "renders the invitation … with escaped user input" (Task 3).
2. **Header injection through the subject.** An org name with `\r\n` must not start a new header line. Pinned by `render.test.ts` "flattens line breaks in the subject" (Task 1).
3. **Queue messages from an older deploy** (renamed template, `"toString"` as template, missing params, `null` body) must be acked and logged, not retried until the dead-letter queue and not crash the batch. A missing `NITRO_EMAIL_FROM` must be *retried*. Pinned by `templates.test.ts` "throws EmailJobError for an unknown template…" (Task 3) and `email.test.ts` `consumeEmailBatch` + `createEmailDeliverer` tests (Task 4).
4. **Frontend under a base path.** `NITRO_APP_URL=https://x.test/admin` must give `https://x.test/admin/auth/accept-invitation/…`, not drop `/admin`. Pinned by `auth.emails.test.ts` `buildAppUrl` (Task 5).
5. **Maizzle mangling a placeholder.** If Maizzle URL-encodes `href="{{actionUrl}}"` or emits a malformed slot, the codegen must fail rather than ship a dead button. Pinned by `generate.lib.test.ts` and `generated.test.ts` (Task 2).

```ts
import { EmailJobError } from './errors.ts';

/** `{{camelCase}}` template slots. Whitespace inside the braces is allowed. */
export const SLOT_TOKEN = /\{\{\s*([a-z]\w*)\s*\}\}/gi;

export function extractSlots(source: string): string[] {
  const slots = new Set<string>();

  for (const match of source.matchAll(SLOT_TOKEN)) {
    if (match[1]) {
      slots.add(match[1]);
    }
  }

  return [...slots].sort();
}

/** Single pass: text inserted for one slot is never scanned for more slots. */
export function fillSlots(source: string, values: Readonly<Record<string, string>>): string {
  return source.replace(SLOT_TOKEN, (_token, slot: string) => {
    const value = Object.hasOwn(values, slot) ? values[slot] : undefined;

    if (value === undefined) {
      throw new EmailJobError(`No value for slot "{{${slot}}}"`);
    }

    return value;
  });
}
```

`packages/server/emails/src/render.ts`:

```ts
import type { CompiledTemplate, RenderedEmail } from './types.ts';
import { EmailJobError } from './errors.ts';
import { fillSlots } from './slots.ts';

const HTML_ESCAPES: Readonly<Record<string, string>> = {
  '&': '&amp;',
  '<': '&lt;',
  '>': '&gt;',
  '"': '&quot;',
  '\'': '&#39;',
};

/** `{camelCase}` params inside locale copy. */
const COPY_TOKEN = /\{([a-z]\w*)\}/gi;

export function escapeHtml(value: string): string {
  return value.replace(/[&<>"']/g, (char) => HTML_ESCAPES[char] ?? char);
}

function identity(value: string): string {
  return value;
}

/**
 * Replaces `{param}` tokens in one copy string. `encode` runs over the literal
 * copy and over every value (pass `escapeHtml` for HTML). Single pass: a value
 * containing `{x}` or `$&` is inserted as-is.
 */
export function formatCopy(
  message: string,
  vars: Readonly<Record<string, string>>,
  encode: (value: string) => string = identity,
): string {
  let output = '';
  let cursor = 0;

  for (const match of message.matchAll(COPY_TOKEN)) {
    const [token, param = ''] = match;
    const value: unknown = Object.hasOwn(vars, param) ? vars[param] : undefined;

    if (typeof value !== 'string') {
      throw new EmailJobError(`Missing value for "{${param}}" in "${message}"`);
    }

    output += encode(message.slice(cursor, match.index)) + encode(value);
    cursor = match.index + token.length;
  }

  return output + encode(message.slice(cursor));
}

/** Only absolute http(s) links may fill a URL slot. Returns the normalized href. */
export function assertHttpUrl(value: unknown, slot: string): string {
  let url: URL;

  try {
    url = new URL(String(value));
  }
  catch {
    throw new EmailJobError(`Slot "${slot}" needs an absolute URL, got "${String(value)}"`);
  }

  if (url.protocol !== 'https:' && url.protocol !== 'http:') {
    throw new EmailJobError(`Slot "${slot}" only accepts http(s) URLs, got "${url.protocol}"`);
  }

  return url.href;
}

export interface RenderCompiledInput {
  compiled: CompiledTemplate;
  /** One template's copy in one locale. `subject` is the subject; every other key fills the slot of the same name. */
  copy: Readonly<Record<string, string>>;
  /** Values for `{param}` tokens in the copy. Untrusted. */
  vars: Readonly<Record<string, string>>;
  /** Slots that hold links. Must be absolute http(s) URLs. */
  urls: Readonly<Record<string, string>>;
}

export function renderCompiled({ compiled, copy, vars, urls }: RenderCompiledInput): RenderedEmail {
  const { subject, ...slotCopy } = copy;

  if (typeof subject !== 'string') {
    throw new EmailJobError('Copy has no "subject"');
  }

  const htmlValues: Record<string, string> = {};
  const textValues: Record<string, string> = {};

  for (const [slot, value] of Object.entries(urls)) {
    const href = assertHttpUrl(value, slot);
    htmlValues[slot] = escapeHtml(href);
    textValues[slot] = href;
  }

  for (const [slot, message] of Object.entries(slotCopy)) {
    htmlValues[slot] = formatCopy(message, vars, escapeHtml);
    textValues[slot] = formatCopy(message, vars);
  }

  return {
    subject: formatCopy(subject, vars).replace(/\s*[\r\n]+\s*/g, ' ').trim(),
    html: fillSlots(compiled.html, htmlValues),
    text: fillSlots(compiled.text, textValues),
  };
}
```

```ts
import type { EmailLocale } from './types.ts';
import { DEFAULT_EMAIL_LOCALE, EMAIL_LOCALES } from './types.ts';

function primaryTag(tag: string): string {
  return tag.split('-')[0] ?? tag;
}

/**
 * Picks the best supported locale from an `Accept-Language` header value:
 * highest `q` first, and for each tag an exact match before a language-only
 * match (`en-GB` → `en-US`). Falls back to `DEFAULT_EMAIL_LOCALE`.
 */
export function matchEmailLocale(acceptLanguage: string | null | undefined): EmailLocale {
  if (!acceptLanguage) {
    return DEFAULT_EMAIL_LOCALE;
  }

  const ranked = acceptLanguage
    .split(',')
    .map((part, index) => {
      const [tag = '', ...params] = part.trim().split(';');
      const q = params.map((param) => param.trim()).find((param) => param.startsWith('q='));
      const quality = q === undefined ? 1 : Number(q.slice(2));

      return { tag: tag.trim().toLowerCase(), quality: Number.isFinite(quality) ? quality : 0, index };
    })
    .filter((entry) => entry.tag !== '' && entry.tag !== '*' && entry.quality > 0)
    .sort((a, b) => b.quality - a.quality || a.index - b.index);

  for (const { tag } of ranked) {
    const match = EMAIL_LOCALES.find((locale) => locale.toLowerCase() === tag)
      ?? EMAIL_LOCALES.find((locale) => primaryTag(locale.toLowerCase()) === primaryTag(tag));

    if (match) {
      return match;
    }
  }

  return DEFAULT_EMAIL_LOCALE;
}
```

```ts
// cspell:ignore maizzle
import { extractSlots, SLOT_TOKEN } from '../src/slots.ts';

/** `reset-password` → `resetPasswordCompiled` */
export function toExportName(name: string): string {
  const camel = name.replace(/-([a-z0-9])/g, (_match, char: string) => char.toUpperCase());

  return `${camel}Compiled`;
}

/** Fails the build when Maizzle rewrote or broke a `{{slot}}` placeholder. */
export function assertCleanPlaceholders(source: string, label: string): void {
  if (/%7B%7B/i.test(source)) {
    throw new Error(`${label}: URL-encoded placeholder (%7B%7B) found. Maizzle rewrote a {{slot}} inside an attribute.`);
  }

  const opened = source.split('{{').length - 1;
  const valid = Array.from(source.matchAll(SLOT_TOKEN)).length;

  if (opened !== valid) {
    throw new Error(`${label}: malformed placeholder. Slots must look like {{camelCase}}.`);
  }
}

export function toCompiledModule(name: string, html: string, text: string): string {
  assertCleanPlaceholders(html, `${name}.html`);
  assertCleanPlaceholders(text, `${name}.txt`);

  const slots = extractSlots(`${html}\n${text}`);

  return [
    '/* eslint-disable */',
    '// cspell:disable',
    `// Generated by scripts/generate.ts from emails/${name}.vue. Do not edit.`,
    '// Run `pnpm --filter @taman/emails build:templates` after changing a template.',
    'import type { CompiledTemplate } from \'../types.ts\';',
    '',
    `export const ${toExportName(name)}: CompiledTemplate = {`,
    `  slots: ${JSON.stringify(slots)},`,
    `  html: ${JSON.stringify(html)},`,
    `  text: ${JSON.stringify(text)},`,
    '};',
    '',
  ].join('\n');
}
```

```ts
const outDir = join(root, 'src', 'generated');

const htmlFiles = (await readdir(buildDir)).filter((file) => file.endsWith('.html')).sort();

  throw new Error(`No .html files in ${buildDir}. Run "maizzle build" first.`);

  const html = await readFile(join(buildDir, file), 'utf8');

  await writeFile(join(outDir, `${name}.ts`), toCompiledModule(name, html, text));
  process.stdout.write(`generated src/generated/${name}.ts\n`);
}

await rm(buildDir, { recursive: true, force: true });
```

```ts
import type { InvitationParams } from './templates/invitation.ts';
import type { ResetPasswordParams } from './templates/reset-password.ts';
import type { VerifyEmailParams } from './templates/verify-email.ts';
import type { EmailLocale, RenderedEmail } from './types.ts';
import { EmailJobError } from './errors.ts';
import { renderInvitation } from './templates/invitation.ts';
import { renderResetPassword } from './templates/reset-password.ts';
import { renderVerifyEmail } from './templates/verify-email.ts';
import { DEFAULT_EMAIL_LOCALE, EMAIL_LOCALES } from './types.ts';

export interface EmailTemplateParams {
  'invitation': InvitationParams;
  'verify-email': VerifyEmailParams;
  'reset-password': ResetPasswordParams;
}

export type EmailTemplateName = keyof EmailTemplateParams;

/** Everything needed to render and send one email. JSON-safe, so it can travel through a queue. */
export type EmailJob = {
  [K in EmailTemplateName]: {
    template: K;
    to: string;
    locale: EmailLocale;
    params: EmailTemplateParams[K];
  };
}[EmailTemplateName];

const renderers: { [K in EmailTemplateName]: (params: EmailTemplateParams[K], locale: EmailLocale) => RenderedEmail } = {
  'invitation': renderInvitation,
  'verify-email': renderVerifyEmail,
  'reset-password': renderResetPassword,
};

function isEmailLocale(value: unknown): value is EmailLocale {
  return (EMAIL_LOCALES as readonly unknown[]).includes(value);
}

/**
 * Renders one job. Jobs may come from a queue written by an older deploy, so
 * the shape is checked at runtime: anything that can never render throws
 * `EmailJobError`.
 */
export function renderEmail(job: EmailJob): RenderedEmail {
  const candidate: unknown = job;

  if (typeof candidate !== 'object' || candidate === null) {
    throw new EmailJobError('Email job must be an object');
  }

  const { template, locale, params } = candidate as { template?: unknown; locale?: unknown; params?: unknown };

  if (typeof template !== 'string' || !Object.hasOwn(renderers, template)) {
    throw new EmailJobError(`Unknown email template "${String(template)}"`);
  }

  if (typeof params !== 'object' || params === null) {
    throw new EmailJobError(`Email job "${template}" has no params`);
  }

  const render = renderers[template as EmailTemplateName] as (params: object, locale: EmailLocale) => RenderedEmail;

  return render(params, isEmailLocale(locale) ? locale : DEFAULT_EMAIL_LOCALE);
}
```

```ts
export interface EmailAddress {
  email: string;
  name?: string;
}

export interface OutgoingEmail {
  to: string;
  from: EmailAddress;
  subject: string;
  html: string;
  text: string;
}

/** How an email leaves the app. One implementation per provider. */
export interface EmailSender {
  send: (email: OutgoingEmail) => Promise<void>;
}

/** When an email leaves the app: during the request (inline) or later (queue). */
export interface EmailDispatcher {
  dispatch: (job: EmailJob) => Promise<void>;
}

/** Renders and sends one job. Shared by both dispatchers and the queue consumer. */
export type DeliverEmail = (job: EmailJob) => Promise<void>;

/** Structural subset of Cloudflare's `SendEmail` binding (wrangler `send_email`). */
export interface SendEmailBinding {
  send: (message: {
    to: string;
    from: string | { email: string; name: string };
    subject: string;
    html: string;
    text: string;
  }) => Promise<{ messageId: string }>;
}

/** Structural subset of a Cloudflare Queue producer binding. */
export interface EmailQueueBinding {
  send: (body: EmailJob) => Promise<unknown>;
}

/** The Worker bindings email uses (see nitro.config.ts). Both are optional. */
export interface EmailEnv {
  EMAIL?: SendEmailBinding;
  EMAIL_QUEUE?: EmailQueueBinding;
}
```

```ts
import { consola } from 'consola';

/** `john.doe@example.com` → `j***@example.com`. Keeps logs useful without full addresses. */
export function maskEmail(address: string): string {
  const at = address.lastIndexOf('@');

  if (at < 1) {
    return '***';
  }

  return `${address[0]}***${address.slice(at)}`;
}

/** Safe for any queue body, including `null` or a job from an older deploy. */
export function logDeliveryError(job: unknown, error: unknown): void {
  const { template, to } = (typeof job === 'object' && job !== null ? job : {}) as { template?: unknown; to?: unknown };
  const recipient = typeof to === 'string' ? maskEmail(to) : 'unknown recipient';

  consola.error(`[EMAIL] failed to deliver "${String(template)}" to ${recipient}`, error);
}
```

```ts
export interface EmailDelivererOptions {
  sender: EmailSender;
  from: EmailAddress;
}

/**
 * Renders one job and hands it to the sender. A missing from-address is a
 * plain `Error` (config can be fixed, so the queue retries). A job that can
 * never render or has no recipient is an `EmailJobError`.
 */
export function createEmailDeliverer({ sender, from }: EmailDelivererOptions): DeliverEmail {
  return async (job) => {
    if (!from.email) {
      throw new Error('NITRO_EMAIL_FROM is not set; cannot send email.');
    }

    const to: unknown = (job as { to?: unknown } | null)?.to;

    if (typeof to !== 'string' || !to.includes('@')) {
      throw new EmailJobError('Email job has no valid recipient');
    }

    const rendered = renderEmail(job);

    await sender.send({ to, from, ...rendered });
  };
}
```

```ts
import type { EmailJob } from '@taman/emails';
import type { DeliverEmail } from './email.types.ts';
import { EmailJobError } from '@taman/emails';
import { logDeliveryError } from './email.log.ts';

/** Must match the queue names in nitro.config.ts (`cloudflare.wrangler.queues`). */
export const EMAIL_QUEUE_NAME = 'taman-email';

/** Structural subset of a Cloudflare Queues `Message`. */
export interface EmailQueueMessage {
  readonly body: unknown;
  ack: () => void;
  retry: () => void;
}

/** Structural subset of a Cloudflare Queues `MessageBatch`. */
export interface EmailQueueBatch {
  readonly queue: string;
  readonly messages: readonly EmailQueueMessage[];
}

/**
 * Delivers each message. Success → ack. `EmailJobError` → log + ack (retrying
 * can't fix it). Anything else → log + retry; after `max_retries` Cloudflare
 * moves the message to the dead-letter queue.
 */
export async function consumeEmailBatch(
  batch: EmailQueueBatch,
  deliver: DeliverEmail,
  onError: (job: unknown, error: unknown) => void = logDeliveryError,
): Promise<void> {
  for (const message of batch.messages) {
    try {
      await deliver(message.body as EmailJob);
      message.ack();
    }
    catch (error) {
      onError(message.body, error);

      if (error instanceof EmailJobError) {
        message.ack();
      }
      else {
        message.retry();
      }
    }
  }
}
```

```ts
import type { DeliverEmail, EmailDispatcher, EmailEnv } from './email.types.ts';
import { useRuntimeConfig } from 'nitro/runtime-config';
import { createEmailDeliverer } from './email.deliver.ts';
import { createInlineEmailDispatcher } from './email.dispatcher.inline.ts';

import { createCloudflareEmailSender } from './email.sender.cloudflare.ts';

export interface EmailConfig {
  emailFrom: string;
  emailFromName: string;
}

export interface EmailServices {
  dispatcher: EmailDispatcher;
  deliver: DeliverEmail;
}

/**
 * The only place that decides how email leaves the app.
 *
 * - `EMAIL` binding → Cloudflare Email Service; otherwise the console sender (`nitro dev` / Node).
 * - `EMAIL_QUEUE` binding → queue dispatcher (retries via `plugins/email-queue.ts`); otherwise inline.
 */
export function createEmailServices(env: EmailEnv | undefined, config: EmailConfig): EmailServices {
  const sender = env?.EMAIL ? createCloudflareEmailSender(env.EMAIL) : createConsoleEmailSender();
  const deliver = createEmailDeliverer({
    sender,
    from: { email: config.emailFrom, name: config.emailFromName || undefined },
  });
  const dispatcher = env?.EMAIL_QUEUE
    ? createQueueEmailDispatcher(env.EMAIL_QUEUE)
    : createInlineEmailDispatcher(deliver);

  return { dispatcher, deliver };
}

 * the Worker env on every request and the queue plugin passes the hook's env,
 * so the first call on an isolate always sees the bindings. Better Auth
 * callbacks call it without arguments.
 */
export function useEmail(env?: EmailEnv): EmailServices {
  services ??= createEmailServices(env, useRuntimeConfig());

  return services;
}
```

```ts
import type { EmailJob, EmailLocale } from '@taman/emails';
import { matchEmailLocale } from '@taman/emails';

/**
 * Frontend route that accepts an invitation. The page itself is a follow-up:
 * the frontend only has /auth/login today.
 */
export const ACCEPT_INVITATION_PATH = 'auth/accept-invitation';

/**
 * Joins `path` onto the frontend base URL and keeps any base path:
 * `https://x.test/admin` + `auth/y` → `https://x.test/admin/auth/y`.
 */
export function buildAppUrl(base: string, path: string): string {
  if (!base) {
    throw new Error('NITRO_APP_URL is not set; cannot build email links.');
  }

  const root = base.endsWith('/') ? base : `${base}/`;

  return new URL(path.replace(/^\/+/, ''), root).href;
}

/** Locale of the request that triggered the email (the inviter for invitations). */
export function emailLocale(request?: Request): EmailLocale {
  return matchEmailLocale(request?.headers.get('accept-language'));
}

/** The fields of Better Auth's `sendInvitationEmail` payload used here. */
export interface InvitationEmailData {
  id: string;
  email: string;
  role: string;
  organization: { name: string };
  invitation: { expiresAt: Date };
  inviter: { user: { name: string; email: string } };
}

export function invitationEmailJob(
  data: InvitationEmailData,
  options: { appUrl: string; locale: EmailLocale },
): EmailJob {
  return {
    template: 'invitation',
    to: data.email,
    locale: options.locale,
    params: {
      inviterName: data.inviter.user.name,
      inviterEmail: data.inviter.user.email,
      organizationName: data.organization.name,
      role: data.role.split(',').map((role) => role.trim()).filter(Boolean).join(', '),
      inviteUrl: buildAppUrl(options.appUrl, `${ACCEPT_INVITATION_PATH}/${encodeURIComponent(data.id)}`),
      expiresAt: new Date(data.invitation.expiresAt).toISOString(),
    },
  };
}

/** The fields of Better Auth's `sendVerificationEmail` / `sendResetPassword` payloads used here. */
export interface AuthLinkEmailData {
  user: { email: string; name: string };
  url: string;
}

export function verifyEmailJob(data: AuthLinkEmailData, locale: EmailLocale): EmailJob {
  return {
    template: 'verify-email',
    to: data.user.email,
    locale,
    params: { name: data.user.name, verifyUrl: data.url },
  };
}

export function resetPasswordEmailJob(data: AuthLinkEmailData, locale: EmailLocale): EmailJob {
  return {
    template: 'reset-password',
    to: data.user.email,
    locale,
    params: { name: data.user.name, resetUrl: data.url },
  };
}
```

````markdown
## Delivery (backend)

`apps/api` chooses delivery by which Worker bindings exist:

| Bindings | Behavior |
|---|---|
| none (`nitro dev`) | inline, printed to the console |
| `EMAIL` | inline, Cloudflare Email Service |
| `EMAIL` + `EMAIL_QUEUE` | queued to `taman-email`, sent by the `cloudflare:queue` consumer with 5 retries, then `taman-email-dlq` |

Cloudflare setup:

1. Onboard the sender domain in Cloudflare Email Service (the dashboard adds the SPF/DKIM records).
2. `npx wrangler queues create taman-email` and `npx wrangler queues create taman-email-dlq`,
   or delete the `queues` block in `nitro.config.ts` to send inline.
3. Set `NITRO_EMAIL_FROM` (an address on that domain), optional `NITRO_EMAIL_FROM_NAME`,
   and `NITRO_APP_URL` (the frontend URL used in invitation links).

Another provider: implement `EmailSender` (`send(email)`) next to
`email.sender.cloudflare.ts` and select it in `server/email/index.ts`.
````
